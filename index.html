Get started

# Clone it once, then open it straight off the filesystem
git clone https://github.com/ayazmirza54/aws.manual
xdg-open aws.manual/manual.html   # macOS: open aws.manual/manual.html
# Any static file server works; this one ships with Python
cd aws.manual && python3 -m http.server 8000
# then visit http://localhost:8000

There is no build step and nothing to install. Served over HTTP it also registers a service worker, so it keeps working with the network unplugged and installs as an app.

Why use aws.manual?

  • The official docs say what each AWS service does, and rarely which parts will bite you.
  • The Open Guide is field notes from engineers who run AWS: tips, gotchas, lock-in and cost.
  • You know you should read it before you build, but it is one 380 KB README.
  • aws.manual splits it into 65 linkable pages with search and a command line.

A real command line

  • ls and tree list the guide, man opens a section, and cat or head print it as text.
  • grep searches the full text and tags gotcha ranks sections by a legend mark.
  • TAB completes commands and section names, and ↑ ↓ walk your history.
  • star, stars and recent keep your place between visits.

Offline by design

  • The whole guide is one static page of about 660 KB, with no CDN, no analytics and no fetch().
  • The fonts are in the repository, so nothing is requested from a font service.
  • It opens from file://, which means a USB stick or a laptop in airplane mode is enough.
  • Served over HTTP, a cache-first service worker keeps it available with the network unplugged.

Keyboard first

  • CTRL K opens search from anywhere, and / filters the section list.
  • [ and ] step to the previous and next section.
  • ? lists every shortcut, and ESC closes whatever is open.
  • Typing any other key puts you straight at the prompt.
ctrlksearch /filter []prev · next ?help

Yours to adjust

  • theme switches between orange, lime, ice, synth and paper, and this page follows your choice.
  • font + and font - change the reading size, and crt on adds scanlines.
  • Stars, recents and settings stay in your browser’s local storage and go nowhere else.
  • It prints cleanly, with the chrome removed.

FAQ

Is this official AWS documentation?

No. aws.manual is not affiliated with, endorsed by or sponsored by Amazon Web Services. It is a community guide, and each section links to the official docs for the service it covers.

Where does the content come from?

From open-guides/og-aws, vendored at commit cde0294 and unmodified apart from formatting. The upstream guide was last updated in August 2022, so check anything time-sensitive, such as prices and limits, against the current AWS docs.

Does it really work offline?

Yes. After the files are on disk or the page has loaded once over HTTP, it makes no network requests. Only the links that leave the guide need a connection.

Is it free?

Yes. The site’s code is under the MIT license, and the guide’s text is © the og-aws contributors under CC BY 4.0.
